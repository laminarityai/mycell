# The builder keeps no text copied from the examples it reads

The builder's `read_examples` tool shows the model up to five real emails, the first 2000 characters of each, so it can write a spec that fits the admin's actual mail. Only the emails' pointers are stored, but the model can quote them in its reply, in a proposal's summary or in a spec's text, and builder conversations and proposals are stored whole, kept until the org is deleted, and shown to every admin (ADR-0023). That breaks invariant 8. So in a turn that read examples, Mycel checks what it is about to store against the examples' text, with the rule memory uses for facts (ADR-0022): eight words in a row as an example has them is a copy. A copy in the agent's reply is replaced with a marker before the reply is stored. A proposal that copies is refused with a validation issue, like any other invalid spec, so the agent rewrites it in its own words in the same turn. We chose this over not storing the replies of such turns, because the conversation's history and the agent's next turn are rebuilt from what's stored. We chose it over documenting a third exception to invariant 8, because unlike run state and held sends, conversations are kept indefinitely, unencrypted by Mycel, and shown to every admin.

## Consequences

- **What's checked:** the agent's reply text, and each `propose_spec` call's spec and summary, both where `builder_messages` stores the call and in `builder_proposals`. The examples are held only for the turn, so the check runs only on turns that called `read_examples`; a later turn no longer has their text to quote.
- **Streaming:** the admin sees the reply as the model writes it, quote included. Only what's stored is checked, and the admin could already read the email, which comes from their own connection or an org connection.
- **Short fragments pass:** a name, an address, or a subject line under eight words. Memory's facts keep the same kind of fragment. Email addresses are identifiers, not content, so a stored search query such as `from:alice@acme.com`, and a connect attempt's refusal naming the account that was refused, are outside invariant 8.
- **The prompt** also tells the agent not to quote examples, but the check is what keeps copies out, since a model can't be relied on to follow it.
- **Docs:** `docs/architecture.md` already says conversations hold no source content; with the check it becomes true.
