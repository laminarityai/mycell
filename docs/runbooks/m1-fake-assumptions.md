# M1: what the fakes assume about the real APIs

Every behaviour of Nango, Gmail, Drive and Inngest that M1's fakes (`app/src/testing/`) model, with where the claim comes from and how `m1-dogfood.md` checks it live. Checked on 2026-10-20 against the docs, Nango's source on GitHub (`NangoHQ/nango`, master), and read-only calls to our Nango `dev` environment.

**Risk** marks the claims that are unverified or that Mycel's correctness leans on hardest. "Live" means a read-only call to Nango Cloud with our key returned it.

Fakes: `fake-nango.ts` (connections, webhooks, proxy), `fake-nango-sessions.ts`, `fake-nango-connections.ts`, `fake-nango-integrations.ts`, `fake-nango-http.ts` (shared), `fake-gmail.ts`, `fake-drive.ts` with `fake-drive-fields.ts`, `fake-proxied-sources.ts`, `fake-inngest.ts`.
