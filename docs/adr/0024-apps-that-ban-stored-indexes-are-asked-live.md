# Apps whose terms ban stored indexes are asked live

Slack's API terms (effective 2025-10-10) bar keeping "persistent copies, archives, indexes, or long-term data stores" of data fetched through its Data Access and Real-Time Search APIs. So memory stores no facts from Slack, or from any app with the same rule: it answers from them by searching the app when someone asks, through that person's connection. Discovery may still count patterns there (how often, who, which channel) without keeping what was said. We'll revisit if a Marketplace listing or a separate agreement changes the terms.
